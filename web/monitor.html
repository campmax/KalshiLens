How to read this screen

Historical deviation: compares the current midpoint with a median of earlier observations. It can identify an unusual move, but it cannot establish the true chance of an event. Sustained moves reset that reference.

Independent estimate: compares executable costs with a probability and range supplied in monitor_config.json. These estimates need a source and expiry. If an external forecasting program updates that file, the next cycle uses the new information.

YES gap: reference minus current midpoint. +5¢ means YES is 5¢ below that reference; −5¢ means 5¢ above. This differs from a purchase edge because you must pay an ask price and fees. A more expensive YES quote may make NO worth examining.

Net gap: uses the pessimistic end of the reference range minus purchase cost per contract and a buffer. History ranges are heuristic noise bands, not calibrated confidence intervals. Model ranges are supplied assumptions. Nothing here proves profit or automatically processes news.

At least eight good observations are needed for history. A move must persist across two captures; isolated outliers are quarantined, and five consecutive large moves trigger a baseline reset. Quotes that are old, one-sided, crossed, too wide, closed or insufficient for the requested size do not produce current candidates.

The collector must remain running on this computer. Refreshes use completed sequential REST snapshots; this is not an exchange streaming feed.
